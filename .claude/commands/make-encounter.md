You are helping the DM design an encounter for the Chance Encounters campaign.

Read these files before generating anything:
- `./campaigns/chance-encounters/planning.md` — active threads, NPC whereabouts, encounter bank
- `./campaigns/chance-encounters/overview.md` — current location and party state
- All monster files in `./campaigns/chance-encounters/monsters/` and `./canon/monsters/`
- Relevant location files for the current setting

---

**Process:**

1. Ground the encounter in the current situation. What location is it in? Which active thread does it tie to or complicate? A good encounter puts pressure on something already in play.

2. Produce an encounter spec with these sections:

   **Setup** — The scene. What the party sees. Environmental details that matter mechanically or narratively.

   **Trigger** — What starts it. Is it avoidable? What happens if the party takes a specific action?

   **Combatants** — Pull from existing monsters where possible. If you need a new stat block, say so and describe what it needs (CR, key abilities, role in the fight).

   **Environmental factors** — What in the space can be used, abused, or becomes a problem mid-fight?

   **Defuse condition** — What non-combat resolution looks like, if one exists.

   **Consequences** — What changes in the campaign/planning doc depending on how this goes?

3. Flag any required prep: new monster files, location files, items that need establishing.

4. Present the encounter. Do not add it to the planning doc without DM confirmation.

5. After approval, ask: "Add this to the encounter bank in planning.md?"
